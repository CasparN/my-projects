# Over Mij

Ik ben Caspar Niekus, derdejaars HBO-ICT student met een focus op embedded software engineering. Ik werk graag op de grens tussen hardware, firmware en backend-systemen: plekken waar software niet alleen op een scherm bestaat, maar iets fysieks aanstuurt, meet of verbetert.

## Hoe ik werk

Ik hou van projecten waarin nog niet alles duidelijk is. Ik wil dingen oplossen, op een mooie manier. Reverse engineering, testen, meten, documenteren en stap voor stap betrouwbaarheid opbouwen passen goed bij mij. In mijn projecten zie je dat terug in low-power firmware, sensordata, robotica, security-analyse en autonome meetsystemen.

## Buiten mijn studie

Naast mijn technische werk ben ik actief binnen scouting, waar ik elke vrijdagavond met een team van andere vrijwilligers een opkomst neerzet voor kinderen van 7-11. Ook gaan wij elk jaar een week op kamp. Hier heb ik geleerd om verantwoordelijkheid te nemen, opkomsten en kampen te organiseren en goed om te kunnen gaan met kinderen.

Ook heb ik ervaring als studentmentor, waarbij ik in de les de docenten assisteer en vragen beantwoord van eerstejaars studenten. Ook heb ik als studentmentor een les gegeven over hardware in een collegezaal.
