# Over Mij

Ik ben Caspar Niekus, vierdejaars HBO-ICT student met een focus op embedded software engineering. Ik werk graag op de grens tussen hardware, firmware en backend-systemen: plekken waar software niet alleen op een scherm bestaat, maar iets fysieks aanstuurt, meet of verbetert. 

Vanaf februari 2027 ben ik beschikbaar voor een HBO-ICT afstudeeropdracht van twintig weken.

## Hoe ik werk

Ik hou van projecten waarin nog niet alles duidelijk is. Ik wil dingen oplossen, op een mooie manier. Reverse engineering, testen, meten, documenteren en stap voor stap betrouwbaarheid opbouwen passen goed bij mij. In mijn projecten zie je dat terug in low-power firmware, sensordata, robotica, security-analyse en autonome meetsystemen.

Ik ben nieuwsgierig, werk graag zelfstandig en duik graag diep in technische problemen. Tegelijkertijd vind ik het belangrijk om eerlijk te blijven over wat ik nog niet weet. Juist daarom zoek ik voor mijn afstudeerstage een omgeving met ervaren engineers, waar ik verantwoordelijkheid kan nemen en inhoudelijk uitgedaagd word.

## Buiten mijn studie

Naast mijn technische werk ben ik actief bij scouting. Iedere vrijdagavond organiseer ik samen met andere vrijwilligers een opkomst voor kinderen van 7 tot 11 jaar. Daarnaast gaan we ieder jaar een week op kamp. Daar heb ik veel geleerd over verantwoordelijkheid nemen, activiteiten en kampen organiseren en duidelijk communiceren met zowel kinderen als andere vrijwilligers.

Daarnaast heb ik twee jaar ervaring als studentmentor. In die rol ondersteun ik docenten tijdens lessen en help ik eerstejaarsstudenten met technische en inhoudelijke vragen. Ook heb ik zelf een les over hardware gegeven in een collegezaal.
